## 本次主要更新

1. **全新 UI 改版**：全站扁平化设计，配色统一为黑白蓝三色体系，视觉更轻盈、层级更清晰。
2. **新增商城系统**：装扮、优惠券、券包、权益卡四大板块上线，详细介绍请转至 [Wiki 商城系统说明](https://deyuen.pages.dev/wiki/guide:商城系统说明) 查看。
3. **社区活动页升级**：钻制潜影盒与铁制末影箱抽奖机迁移至商城；留言墙新增头像显示；上线彩票与刮刮乐玩法，详见下方更新提醒。
4. **打卡系统重构**：打卡周期由自然日改为自然周，同一自然周内可补签，每日发放不同奖励，详见下方更新提醒。
5. **账号页升级**：新增「我的装扮」与「券包与权益」管理区，佩戴、切换、用券一站完成。
6. 修复了一些已知问题。

## 本次更新提醒

### 1. UI 改版须知

- 全站组件已扁平化：去除多余阴影与渐变，改用细边框与色块区分层级。
- 配色采用黑白蓝三色体系：白色为底、黑色为文、蓝色为强调色，链接与按钮全部统一。
- 如遇个别页面样式异常，请强制刷新（Ctrl + F5）后重试；仍有问题请前往追踪中心反馈。

### 2. 社区活动页调整

- **抽奖机迁移**：钻制潜影盒与铁制末影箱抽奖机已从社区活动页迁移至商城，原有免费抽奖券继续有效，请前往商城对应入口使用。
- **留言墙头像**：留言墙现在会显示留言者的头像，查找熟人更方便。
- **彩票与刮刮乐上线**：新玩法与抽奖机相互独立，详见下文第 3 节。

### 3. 彩票与刮刮乐系统

- 彩票与刮刮乐均为站内虚拟积分玩法，**奖励为积分**。
- 积分仅用于站内消费，**不对等人民币，不可兑换人民币，不可提现、转让或交易**。
- 现有玩法：SSQ（双色球）、K8（快乐8）、D3（3D），玩法规则对应现实福利彩票；刮刮乐中奖结果由公式计算。
- **期望值较低，不保证回本**。结果随机，请理性参与，仅供娱乐，不构成任何形式的赌博、投资或金融产品。
- 禁止外挂、脚本、多账号套利或异常请求；系统检测到异常将取消奖励并视情况封禁。
- 如遇奖励未到账、概率显示异常等问题，请携带截图前往追踪中心反馈。

### 4. 打卡补签（重构）

- 打卡周期：由自然日改为**自然周**，按北京时间（UTC+8）计算，具体起止以页面显示为准。
- 补签范围：同一自然周内可补签本周未打卡的日期；跨周后不可补签上一周。
- 补签消耗：按该日奖励计算，公式为

  补签消耗 = floor(该日奖励 × 2 / 3)

  示例：奖励 12 → 消耗 8；奖励 10 → 消耗 6；奖励 8 → 消耗 5；奖励 6 → 消耗 4。
- 补签奖励：补签成功后照常发放该日原奖励；缺卡黄格转为已打卡绿格。
- 特别提醒：补签发放奖励，但**是否计入连续打卡与称号结算，以页面实际显示为准**。
- 入口：社区活动页打卡周历中，缺卡日（黄格）可直接点击补签。
- 异常处理：每账号每日仅计一次有效打卡或补签；系统检测到异常频率、设备或 IP 异常时，不计奖励。

### 5. 新商城玩法

商城以积分为唯一货币，入口在社区导航「商城」：

| 板块 | 内容 | 说明 |
|---|---|---|
| 装扮 | 头像框 / 主题 / 徽章 / 签名档 / 彩色 / 置顶卡 | 6 大品类 36 件商品，购买后永久有效 |
| 优惠券 | 9 折 ~ 5 折 / 免单券 | 额度可拆多次使用，统一 365 天有效 |
| 券包 | 600 ~ 40000 共 9 档 | 三合一 / 单品类 / 组合 / 订阅四种形态，券面总额为售价 1.2 倍 |
| 权益卡 | 发言加成 / 打卡加成 / 免费置顶 / 装扮体验 | 时效卡激活即生效并自动佩戴，按次卡用完即止 |
| 抽奖 | 钻制潜影盒 / 铁制末影箱 | 由社区活动页迁移而来，原有免费抽奖券继续有效 |

**特别提醒：**

1. 结算时优惠券与限时活动互斥，系统自动取实付更低的一方；同价时优先使用活动，为你省下一张券。
2. 也可在下单时手动指定用券，指定后以你的选择为准。
3. 时效体验卡在有效期内限购一份；多张同类装扮卡并存时，可在商城或账号页「设为生效」切换佩戴。
4. 商城详细规则（券经济模型、券包档位表、权益卡规则、结算示例）共 4 篇，见 [Wiki 商城系统说明](https://deyuen.pages.dev/wiki/guide:商城系统说明)。

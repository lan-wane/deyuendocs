> 在您使用本网站前，请您务必确保已完整阅读本更新公告，并充分理解、支持公告中的各项条款。如不认同，请您立即停止使用。

## 本次主要更新

1. 登录态绑定：发表提案与评论现须登录主站账号。
2. 新增投票功能：提案支持所有人投票，投票入口见提案详情页。
3. Issue 评论功能：Bug 与提案均开放评论区，可在详情页参与讨论。
4. 设备环境采集：Bug 反馈现自动附带设备环境与上下文信息。
5. 修复了一些已知问题。

## 本次更新提醒

### 1. 登录态说明

首次进入后，登录态可能失效，需前往主站重新登录。追踪中心检测到未登录时，将在 2.5 秒内自动跳转至主站登录页。

### 2. 投票功能须知

- 投票结果仅供参考，不代表最终处理结果，最终由管理员决定处理方案。
- 每人一票：每个 IP 仅可投票一次。
- 全员可投：所有人（含未登录用户）均可参与投票。

### 3. Issue 评论功能须知

- Issue 评论用于讨论提案或 Bug，请保持友善、聚焦问题本身。
- 请勿将 Issue 评论区用于争吵或闲聊，一经发现将作禁言处理。

### 4. 设备环境采集说明

- 设备环境采集依赖浏览器 API，数据未必完全准确。
- 如发现环境信息与实际不符，可手动修改。
- 数据仅用于 Bug 修复参考。

# 购买结算与活动规则

商城入口为 [[mark:/shop]]，券与卡的管理入口为账号页 [[mark:「券包与权益」]]。本文说明下单时的优惠计算方式，以及优惠券与限时活动的取舍规则。

## 三类商品的购买规则

?list tBuy =
?theme striped
?thead
| 商品 | 购买限制 | 备注 |
?tbody
| 普通商品 | 永久装扮每件限购一次，置顶卡可重复购买 | 已拥有时下单会给出提示 |
| 券包 | 每账号限购 1 份 | 单品类券包需选择品类，组合包需选择赠品 |
| 权益卡 | 入库后可囤放 | 时效体验卡限购一份 |
^tBuy

## 券与活动互斥

限时活动（满减、满赠、折扣、免单）与优惠券 [[mark:不可叠加]]。结算时自动比较两者，取实付更低的一方；实付相同时优先使用活动，从而 [[mark:保留一张券]]。

**自动模式**（不选券）：系统遍历所有可用券，逐一校验门槛、品类与剩余额度，选出实付最低的一张，再与活动价比较。

?list tMutex =
?theme striped
?thead
| 场景 | 券后价 | 活动价 | 实际生效 |
?tbody
| 2600 商品 + 66 折券（封顶 1020） | 1716 | 满 2000 减 800 → 1800 | 使用券，实付 1716 |
| 2600 商品 + 活动 65 折 | 1716 | 1690 | 使用活动，券保留 |
| 2600 商品 + 满 2000 返 2000 积分 | 1716 | 2600 返 2000 | 实付相同时优先活动，券保留 |
^tMutex

**手动模式**：下单时可在选券框指定任意一张可用券。指定后 [[mark:按指定券结算]]，不再与活动比较；选择「不使用优惠券」则按原价或活动价结算。

[[tip:满赠（无论来自券或活动）返还的积分在下单成功后实时到账。]]

[[warn:积分不足——下单前请确认余额，失败不会产生部分扣款。]]

[[err:该券不可用——未达门槛、品类不符或额度已用完，选券框会给出具体原因。]]

[[note:该体验卡仍在有效期内——时效体验卡到期后方可再次购买。]]

## 活动类型

活动由后台配置，包含单笔门槛、优惠数值、适用品类（可限定品类或全品类）、起止时间与开关：

?list tActs =
?theme striped
?thead
| 类型 | 效果 | 说明 |
?tbody
| 满减 | 满 X 减 Y | 直接减免 |
| 满赠 | 满 X 返 Y 积分 | 不消耗券 |
| 折扣 | 满 X 享 Y 折 | 按万分比计算 |
| 免单 | 满 X 免单 | 实付 1 积分 |
^tActs

## 账号页管理

账号页「券包与权益」为券与卡的统一管理处，提供以下功能：

- 查看每张券的剩余额度、使用门槛、有效期与来源
- 激活权益卡（装扮类激活后即佩戴）
- 多张装扮卡冲突时，通过「设为生效」一键切换
- 查看订阅券包的已发期数与下一期发放时间
